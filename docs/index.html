功能

万能调音

YIN 加谐波模型精化，音准误差 ±0.5 cent；可调噪声门限、两帧确认与迟滞；极光表盘单指针无残影；固定调 / 首调 / 数字 / 工尺唱名。

专业分析

音乐 / 全范围 FFT、12 秒音高轨迹、实时波形包络、峰值标注、瀑布历史与和弦检测；12/19/24/31 等分参考音与 A4 校准。

乐器调弦

吉他、尤克里里、古琴调弦预设；竹笛、洞箫、尺八指法表；自动目标匹配或手动锁定弦 / 音。

节拍器

Rust 引擎样本级定时，多音色可选；摆锤视觉与触觉反馈，与调音器共享音频通路。

平台

Android

Kotlin + Jetpack Compose，UniFFI Kotlin 绑定，全 ABI 原生库。

iOS

SwiftUI 原生应用，XCFramework 静态链接 Rust core。

macOS

macOS 14+ SwiftUI 桌面应用，侧栏五入口布局。
