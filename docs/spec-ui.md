# spec-ui — 面板交互规格（Android / Compose，iOS / SwiftUI）

四个主面板 + 设置。导航：底部 NavigationBar（调音 / 乐器 / 频谱 / 节拍器 / 设置）。
视觉与动效以 `docs/design-system.md`（「Aurora/极光」v3）为准，本文件只管**行为与交互逻辑**。

## 1. 通用调音面板

- 布局（自上而下，按比例分配，填充率 75–90%，禁止大面积空白/拥挤）：表盘区 → 音名读数 → 唱名+调性胶囊行 → 数据胶囊行 → 频谱分析带 → 泛音/和弦行 → 状态胶囊（底部，仅无信号时）。
- 表盘：10 cents 主刻度、2 cents 细分、彩色分区弧、进度光弧、单指针快速跟随；任何时刻
  只绘制当前偏差的一根实针，不绘制历史帧残影。iOS 使用 50ms 无回弹缓动，避免连续测量
  打断弹簧后产生粘滞或停在过渡位置；Android 保持既有快速弹簧参数。|c|≤5 准音态
  （光涌 + 音名脉冲 + 触觉）。**音名等读数在表盘下方独立区域，永远不与表盘图形重叠。**
- 读数：大字音名（含八度与变音记号）、Hz、±cents、唱名（按设置中的唱名体系与调式）。
- **调性按钮**：唱名胶囊旁的「C 大调 ▾」胶囊，点击从胶囊处**浮动展开**调性面板（12 主音 × 大调/小调/宫/商/角/徵/羽）；展开时背景下沉+遮罩，收起时弹回，界面随动不留空洞。选中即写入 DataStore 并即时生效（set_solfege），与设置页调式项是同一份数据。固定 Do 时禁用置灰。
- **频谱分析带**：core analyze() 返回的真实 FFT 频谱（64 bin 对数轴），H1–H5 泛音旗标（H1 用语义色）、非泛音峰空心圆点；禁止模拟数据。
- **频谱与指针同步**：主调音页只在 `Tracking` 确认帧替换频谱、峰值和和弦；`Holding`
  及下一音高的首个候选帧继续显示上一次确认内容。专业频谱页始终消费原始实时频谱。
- **频谱峰值频率**：每个实际捕捉到的峰值旗标必须显示一位小数的 Hz 数值。H1 使用当前
  音准语义色，其余实际泛音使用次要文字色；标签相邻时上下错层或水平避让，不得重叠。
  不存在于 `partials` 的理论 H2–H5 不得画旗标。
- **频谱跳转**：整个频谱分析带是一个至少 48dp/pt 高的可访问点击目标，点击切换到
  独立专业频谱页。
- **泛音/和弦行**：泛音 chips（H2/H3… 含 cents 偏差）+ 和弦卡片（core 检测 ≥3 音级时显示如 "Cmaj"，否则「—」）。
- **专业版（PRO）**：右上角 PRO 角标按钮开关（与设置页开关同源）。开启后显示律制胶囊（「12-TET ▾」），点击浮动面板选 12/19/24/31 平均律，即时生效（set_temperament）；数据胶囊行追加律制偏差读数。关闭时新增控件弹簧收起。
- **音叉入口**：页面左上角与右上角 PRO 严格镜像的位置放置音叉按钮；高度、宽度、
  顶部距离和外侧边距相同。它只占用原有空白，不移动表盘、读数、频谱等主体布局。
  点击弹出固定音高浮窗，浮窗存在时主调音器的麦克风采集、Rust 分析和指针显示继续工作。
- **音叉浮窗**：显示 core 按当前 A4 与平均律给出的 80–1500Hz 全部固定音高。点一个音
  持续播放该正弦音；再点同一项停止，点另一项平滑切换。当前选择和播放状态分别明确标识。
  关闭浮窗不停止声音，入口下方出现与 PRO 等宽的快捷停止/继续胶囊，且不推动主体布局。
  离开调音页、应用退到后台或音频会话中断才停止播放，并保留上次选择供返回后恢复。
  律制/A4 改变时刷新音级表、停止播放并清除已失效选择。浮窗不得请求新的权限。
- 无信号：显示完全服从 core 的 `SignalState` 和 `display_strength`。连续两帧有效才出现；
  首次可信读数出现前显示「请发声」；此后断音以完整强度持续保持最近读数，直到下一音高
  连续两帧确认后替换。原生界面不得另设超时清除逻辑。
- 响动即识别（自动模式），无需按键。

## 2. 乐器面板

顶部：乐器选择卡片行（吉他/尤克里里/古琴/竹笛/洞箫/尺八）+ 定弦/调性选择。
所有选择器固定 48dp/pt 高、16dp/pt 圆角、单行省略；禁止因“洞箫”等名称或动态字体而折行。
窄屏下整组按既定顺序换为上下两行，而不是压扁任一控件。展开菜单宽度不得小于触发控件，
当前项需有选中标记。

### 2a. 弦乐器（吉他/尤克里里/古琴）

- 琴弦横排按钮：弦号 + 音名 + 唱名（唱名用预设自带的习惯调唱名，见 spec-instruments）。
- 自动模式（识别最近弦高亮）/ 手动模式（点弦锁定，±50 cents 容差）。
- 下方小型表盘 + 目标读数（目标音名 + ±cents）。
- 某弦 |cents| ≤ 5 时该弦按钮打勾变绿。

### 2b. 管乐器（竹笛/洞箫/尺八）

- 选择：调性/型号 + 筒音唱名（作 5 / 作 1 / 作 2）。
- 指法音阶列表：指法名 + 音名 + 唱名；吹奏时高亮最近音项 + cents 偏差。
- 下方同小型表盘。

主调音和乐器调音共享 core 的输入状态机；乐器页不得用本地定时器清空目标弦、指法或指针。
两个页面还必须复用同一套单指针呈现规则；下一次可信读数到达后立即以该值为唯一目标，
断音进入 `Holding` 时继续显示 core 返回的最后可信位置，不得补画历史针或动画归零。

## 3. 专业频谱面板

- 入口一：底部「频谱」标签；入口二：点击通用调音页的频谱分析带。两者进入同一页面和
  同一导航状态，返回调音页后继续沿用捕捉状态。
- 数据源：与主调音页共享 `CaptureHub` 的实时 `AnalysisFrame`，不得新开第二路麦克风，
  不得使用模拟频谱。
- 主图：对数横轴 60–2400Hz、纵轴 -80–0dBFS，绘制全部 64 个实际频谱 bin；带刻度、
  网格和当前输入电平；绘制实时线与固定峰值保持线，支持触摸/拖动游标查看频率、dB 与
  最近实际峰的音名，并可暂停/继续。横轴固定显示 60/100/200/500/1k/2.4kHz，纵轴固定
  显示 0/-20/-40/-60/-80dBFS；0dBFS 是数字满量程上限，不是当前输入读数。标题区必须
  明确显示「实时刷新」或「已冻结」。主图表达当前频率分布，只随新帧改变幅值，不得伪装成
  沿横轴滚动的时间图。每个频率桶的峰值只允许被更强信号抬高，不按帧衰减，也不因弱信号
  或静音向下漂移。标题区提供「重置峰值」；点击只把各频率桶的峰值保持清到 -80dBFS，
  不清空实时曲线、连续时间图谱、六项摘要或实际峰值列表，也不改变暂停/继续状态。重置后
  下一张有效实时频谱帧重新开始累计峰值。
- 连续时间图谱：横轴与主图同为 60–2400Hz，纵向为时间，最新行在顶部。每 2 个分析帧
  写入一行颜色，固定保留 256 行（约 12 秒），暂停时与主图同时冻结。每行由 64 个真实
  测量桶线性插值为 96 个显示色块；插值只提高视觉细腻度，不增加频谱测量精度。左侧显示
  现在/-3/-6/-9/-12秒，底部显示与主图相同的频率刻度，右侧显示 -80～0dBFS 强度色标。
  颜色按深背景、靛蓝、紫、青、黄、红表达由弱到强的能量，网格必须在各档刻度位置可见。
- 峰值：绘制 `partials` 的所有实际峰，标出 H1/泛音序号、音名和一位小数 Hz；碰撞时错层。
- 摘要：在连续时间图谱前以两行三列显示音名、基频 Hz、音分偏差、输入 dBFS、最强实际峰
  （频率与强度）和和弦；每张摘要卡总高 52dp/pt、行间距 6dp/pt，最强峰允许两行；
  无对应数据时显示短横线，输入电平始终显示当前数值。
- 峰值表：按频率列出实际峰的频率、dB、泛音序号或独立音名，最多使用 core 返回的 8 项。
- 专业页保持原始实时更新，不受主调音页锁存影响；重复频率不得作为列表唯一标识。

## 4. 节拍器面板

- BPM：大字 + 刻度环；垂直拖动 + 滑杆 + ±1/±5；30–250；tap tempo（≥2 次生效）。
- 摆锤动画随拍摆动；拍号 1/4–12/8 常用集；每拍重音圆点（点击循环 重拍/普通/静音）。
- 音色按常用程度显示：机械节拍 / 木块 / 电子滴声 / 拍板 / 边鼓 / 小鼓 / 牛铃 / 踩镲 /
  拍手 / 沙锤 / 低鼓 / 铃声。重拍（默认铃声）与弱拍（默认机械节拍）分别可选；选择状态
  沿用既有保存标识，异常或未知保存值安全回退到对应默认音色。
- 视觉闪拍与小节进度由 TickInfo 驱动。
- 播放/停止大按钮；播放中前台 Service 保活。

## 5. 设置页

- A4 校准：415–466Hz，步进 1Hz（显示 0.1）。
- 唱名体系：固定 Do / 首调 Do / 简谱数字 / 宫商角徵羽。
- 调式：12 主音 × 7 调式（与通用面板调性按钮同一份数据；固定 Do 时禁用）。
- 专业版模式：开 / 关（与通用面板 PRO 角标同源）。
- 律制：12 / 19 / 24 / 31 平均律（专业版开启时可见）。
- 灵敏度（噪声门限）：-60 ~ -30 dBFS，未保存过设置时默认 -45dBFS；既有保存值不迁移。
  显示当前数值，并解释数值越高
  越不容易被小声触发；修改后主调音和乐器调音即时共用。
- 主题：跟随系统 / 浅色 / 深色。
- 触觉反馈：开 / 关（默认开）。

## 6. 通用要求

- 深色/浅色完整适配（浅色无极光，用浅语义色渐变）。
- 行为变更必须同步本文件；视觉/动效变更必须同步 `docs/design-system.md`。
