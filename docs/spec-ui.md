# spec-ui — 面板交互规格（Android / Compose）

三个主面板 + 设置。导航：底部 NavigationBar（调音 / 乐器 / 节拍器 / 设置）。
视觉与动效以 `docs/design-system.md`（「Aurora/极光」v3）为准，本文件只管**行为与交互逻辑**。

## 1. 通用调音面板

- 布局（自上而下，按比例分配，填充率 75–90%，禁止大面积空白/拥挤）：表盘区 → 音名读数 → 唱名+调性胶囊行 → 数据胶囊行 → 频谱分析带 → 泛音/和弦行 → 状态胶囊（底部，仅无信号时）。
- 表盘：10 cents 主刻度、2 cents 细分、彩色分区弧、进度光弧、指针弹簧跟随；|c|≤5 准音态（光涌 + 音名脉冲 + 触觉）。**音名等读数在表盘下方独立区域，永远不与表盘图形重叠。**
- 读数：大字音名（含八度与变音记号）、Hz、±cents、唱名（按设置中的唱名体系与调式）。
- **调性按钮**：唱名胶囊旁的「C 大调 ▾」胶囊，点击从胶囊处**浮动展开**调性面板（12 主音 × 大调/小调/宫/商/角/徵/羽）；展开时背景下沉+遮罩，收起时弹回，界面随动不留空洞。选中即写入 DataStore 并即时生效（set_solfege），与设置页调式项是同一份数据。固定 Do 时禁用置灰。
- **频谱分析带**：core analyze() 返回的真实 FFT 频谱（64 bin 对数轴），H1–H5 泛音旗标（H1 用语义色）、非泛音峰空心圆点；禁止模拟数据。
- **泛音/和弦行**：泛音 chips（H2/H3… 含 cents 偏差）+ 和弦卡片（core 检测 ≥3 音级时显示如 "Cmaj"，否则「—」）。
- **专业版（PRO）**：右上角 PRO 角标按钮开关（与设置页开关同源）。开启后显示律制胶囊（「12-TET ▾」），点击浮动面板选 12/19/24/31 平均律，即时生效（set_temperament）；数据胶囊行追加律制偏差读数。关闭时新增控件弹簧收起。
- 无信号：800ms 无事件 → 指针回中、读数降透明度、底部「请发声」状态胶囊淡入（禁止大号占位文字）。
- 响动即识别（自动模式），无需按键。

## 2. 乐器面板

顶部：乐器选择卡片行（吉他/尤克里里/古琴/竹笛/洞箫/尺八）+ 定弦/调性选择。

### 2a. 弦乐器（吉他/尤克里里/古琴）

- 琴弦横排按钮：弦号 + 音名 + 唱名（唱名用预设自带的习惯调唱名，见 spec-instruments）。
- 自动模式（识别最近弦高亮）/ 手动模式（点弦锁定，±50 cents 容差）。
- 下方小型表盘 + 目标读数（目标音名 + ±cents）。
- 某弦 |cents| ≤ 5 时该弦按钮打勾变绿。

### 2b. 管乐器（竹笛/洞箫/尺八）

- 选择：调性/型号 + 筒音唱名（作 5 / 作 1 / 作 2）。
- 指法音阶列表：指法名 + 音名 + 唱名；吹奏时高亮最近音项 + cents 偏差。
- 下方同小型表盘。

## 3. 节拍器面板

- BPM：大字 + 刻度环；垂直拖动 + 滑杆 + ±1/±5；30–250；tap tempo（≥2 次生效）。
- 摆锤动画随拍摆动；拍号 1/4–12/8 常用集；每拍重音圆点（点击循环 重拍/普通/静音）。
- 音色：机械 click / 电子 beep / 铃声，重拍（默认铃声）与弱拍分别可选。
- 视觉闪拍与小节进度由 TickInfo 驱动。
- 播放/停止大按钮；播放中前台 Service 保活。

## 4. 设置页

- A4 校准：415–466Hz，步进 1Hz（显示 0.1）。
- 唱名体系：固定 Do / 首调 Do / 简谱数字 / 宫商角徵羽。
- 调式：12 主音 × 7 调式（与通用面板调性按钮同一份数据；固定 Do 时禁用）。
- 专业版模式：开 / 关（与通用面板 PRO 角标同源）。
- 律制：12 / 19 / 24 / 31 平均律（专业版开启时可见）。
- 灵敏度（噪声门限）：-60 ~ -30 dBFS。
- 主题：跟随系统 / 浅色 / 深色。
- 触觉反馈：开 / 关（默认开）。

## 5. 通用要求

- 深色/浅色完整适配（浅色无极光，用浅语义色渐变）。
- 行为变更必须同步本文件；视觉/动效变更必须同步 `docs/design-system.md`。
