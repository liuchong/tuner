# spec-ui — 面板交互规格（Android / Compose，iOS/macOS / SwiftUI）

四个主面板 + 设置。导航：底部 NavigationBar（调音 / 乐器 / 频谱 / 节拍器 / 设置）。
视觉与动效以 `docs/design-system.md`（「Aurora/极光」v3）为准，本文件只管**行为与交互逻辑**。

## 1. 通用调音面板

- 布局（自上而下，按比例分配，填充率 75–90%，禁止大面积空白/拥挤）：表盘区 → 音名读数 → 唱名+调性胶囊行 → 数据胶囊行 → 频谱分析带 → 泛音/和弦行 → 状态胶囊（底部，仅无信号时）。
- 表盘：10 cents 主刻度、2 cents 细分、彩色分区弧、进度光弧、单指针快速跟随；任何时刻
  只绘制当前偏差的一根实针，不绘制历史帧残影。iOS 使用 50ms 无回弹缓动，避免连续测量
  打断弹簧后产生粘滞或停在过渡位置；Android 保持既有快速弹簧参数。|c|≤5 准音态
  （光涌 + 音名脉冲 + 触觉）。**音名等读数在表盘下方独立区域，永远不与表盘图形重叠。**
- 读数：大字音名（含八度与变音记号）、Hz、±cents、唱名（按设置中的唱名体系与调式）。
- **调性按钮**：唱名胶囊旁的「C 大调 ▾」胶囊，点击从胶囊处**浮动展开**调性面板（12 主音 × 大调/小调/宫/商/角/徵/羽）；展开时背景下沉+遮罩，收起时弹回，界面随动不留空洞。选中即写入 DataStore 并即时生效（set_solfege），与设置页调式项是同一份数据。固定 Do 时禁用置灰。
- **频谱分析带**：core analyze() 返回的真实 FFT 频谱（64 bin 对数轴），H1–H5 泛音旗标（H1 用语义色）、非泛音峰空心圆点；禁止模拟数据。
- **频谱与指针同步**：主调音页只在 `Tracking` 确认帧替换频谱、峰值和和弦；`Holding`
  及下一音高的首个候选帧继续显示上一次确认内容。专业频谱页始终消费原始实时频谱。
- **频谱峰值频率**：每个实际捕捉到的峰值旗标必须显示一位小数的 Hz 数值。H1 使用当前
  音准语义色，其余实际泛音使用次要文字色；标签相邻时上下错层或水平避让，不得重叠。
  不存在于 `partials` 的理论 H2–H5 不得画旗标。
- **频谱跳转**：整个频谱分析带是一个至少 48dp/pt 高的可访问点击目标，点击切换到
  独立专业频谱页。
- **泛音/和弦行**：泛音 chips（H2/H3… 含 cents 偏差）+ 和弦卡片（core 检测 ≥3 音级时显示如 "Cmaj"，否则「—」）。
- **专业版（PRO）**：右上角 PRO 角标按钮开关（与设置页开关同源）。开启后显示律制胶囊（「12-TET ▾」），点击浮动面板选 12/19/24/31 平均律，即时生效（set_temperament）；数据胶囊行追加律制偏差读数。关闭时新增控件弹簧收起。
- **音叉入口**：页面左上角与右上角 PRO 严格镜像的位置放置音叉按钮；高度、宽度、
  顶部距离和外侧边距相同。它只占用原有空白，不移动表盘、读数、频谱等主体布局。
  点击弹出固定音高浮窗，浮窗存在时主调音器的麦克风采集、Rust 分析和指针显示继续工作。
- **音叉浮窗**：显示 core 按当前 A4 与平均律给出的 80–1500Hz 全部固定音高。点一个音
  持续播放该正弦音；再点同一项停止，点另一项平滑切换。当前选择和播放状态分别明确标识。
  关闭浮窗不停止声音，入口下方出现与 PRO 等宽的快捷停止/继续胶囊，且不推动主体布局。
  离开调音页、应用退到后台或音频会话中断才停止播放，并保留上次选择供返回后恢复。
  律制/A4 改变时刷新音级表、停止播放并清除已失效选择。浮窗不得请求新的权限。
- 无信号：显示完全服从 core 的 `SignalState` 和 `display_strength`。连续两帧有效才出现；
  首次可信读数出现前显示「请发声」；此后断音以完整强度持续保持最近读数，直到下一音高
  连续两帧确认后替换。原生界面不得另设超时清除逻辑。
- 响动即识别（自动模式），无需按键。

## 2. 乐器面板

页面自上而下为：乐器切换条 → 型号控件行 → 乐器图示区 → 目标读数 → 表盘（2026-09-29）。

- **乐器切换条**：六种乐器（吉他/尤克里里/古琴/竹笛/洞箫/尺八）等宽平铺成一行、不横向滚动；
  每格 56dp/pt 高，上方一枚与该乐器同风格的线稿图标，下方乐器名。选中格用主色描边、
  浅主色底与主色图标/文字。按下轻微缩放作为触感反馈。
- **型号控件行**：弦乐为“定弦下拉 + （仅吉他）琴头样式分段 + 自动选弦开关”；管乐为
  “调性/型号下拉 + （有多种孔制时）孔制分段”。
- 所有选择器固定 48dp/pt 高、胶囊形、单行省略；禁止因“洞箫”等名称或动态字体而折行。
  弦乐控件始终同一行；窄屏时收紧内边距、自动选弦开关只留文字、定弦下拉省略，而不是折成两行。展开菜单宽度不得小于触发控件，
  当前项需有选中标记。
- **目标读数**：左侧小字“目标”与目标音名，右侧 ±cents 与“cents”单位；无信号时右侧改为
  “请发声”提示胶囊。自动选弦且没有目标时左侧显示“自动识别”，管乐显示“按指法吹奏”；
  手动锁定某弦时即使无信号也显示该弦音名。读数区高度固定，有无信号不跳动。
- **表盘**：高度随屏高取比例并设上下限，弦乐比管乐略高；图示区占据其余高度。

### 2a. 弦乐器（吉他/尤克里里/古琴）

- 弦按钮统一显示弦号徽标 + 音名 + 唱名（唱名用预设自带的习惯调唱名，见 spec-instruments）。
  当前弦（实时命中或手动锁定）用主色描边与浅主色底；某弦 |cents| ≤ 5 时弦号徽标换为对勾并变绿。
- **自动选弦开关**：点亮（主色实心、声波图标、“自动”）时识别最近的弦；点任意弦按钮或图示中的弦
  即锁定该弦（±50 cents 容差），开关随之熄灭为“手动”；再点开关回到自动。切换乐器时回到自动。
- **吉他 / 尤克里里琴头图**：图示区中央是一幅线稿琴头（琴头轮廓、琴枕、各弦从琴枕连到弦轴柱、
  旋钮），弦音按钮与旋钮同侧、顺序一致，每个按钮用细虚线引到对应旋钮并以圆点收尾，
  说明“哪个旋钮调哪根弦”。
  - 吉他琴头样式用业内通称二选一：**6-in-line**（Fender 式六联排，六个旋钮在低音侧一列，
    6 弦最近琴枕、1 弦在琴头尖端，按钮在同侧一列、自上而下 1…6 弦）与 **3+3**（Gibson 式三加三，
    左侧自下而上 6/5/4 弦、右侧自下而上 1/2/3 弦——两根 E 弦最近琴枕，D、G 弦在顶端）。
    默认 6-in-line；所选样式跨启动保留。
  - 尤克里里为 2+2 琴头：左侧 4、3 弦，右侧 1、2 弦，4、1 弦最近琴枕。
  - 当前弦在琴头图中同步加粗并着色：实时命中/锁定用主色，准音用绿色。点按琴头图中的弦或
    弦轴也等同点对应弦按钮。
- **古琴**：七个弦音按钮横排在上方，下方是一张线稿古琴（琴身、岳山、龙龈、十三徽、七弦与弦号）。
  当前弦在古琴图上加粗并着色，其余弦保持细线；直接点按或沿弦纵向滑过古琴图上的某根弦
  即激活对应弦按钮（进入手动锁定），无障碍提供“上一弦 / 下一弦”操作。

### 2b. 管乐器（竹笛 / 洞箫 / 尺八）

三种管乐统一采用本节的“完整乐器图 + 三音区列”表格（2026-09-29）。下文以洞箫为基准描述，
竹笛与尺八只在乐器图形制、音区命名和可用能力上不同（见本节末条）。图示区外是一张圆角卡片。

- 洞箫调性为 G/F；同一调性可在 8 孔与 6 孔间切换。首次进入或没有可兼容的既有孔制选择时
  默认 8 孔；切换调性/孔制尽量保留当前孔制与筒音唱名。
- 主视图由一支完整大型竖向洞箫与右侧三个音区列组成：**低音（缓吹）**、
  **中音（超吹）**、**高音（急吹）**。这不是恢复普通表格：大洞箫仍是主视觉，
  每个基础行仍由横向引导线与最上方开孔孔心严格对齐。七声主表固定为 7 个基础孔位行，
  十二音详情独立固定为 12 个基础孔位行。三列都显示 core 返回的实测指法：中音区多数沿用
  低音孔位，高音区孔位不同；指法图未覆盖的格（八孔超过 31 半音、六孔列间冲突处）必须
  视觉留白、不可点，也不得显示占位音名。禁止复制低音孔位或用八度/五度偏移合成缺失格。
- 8 孔模式的一支管体恰好显示 8 个孔，6 孔模式恰好显示 6 个孔。每个基础指法行按其
  `anchor_hole` 与最上方开孔孔心严格对齐；全闭行锚定底部出音口。贯穿管身和三列的细辅助线必须持续可见。
  某条物理孔位辅助线在七声主表没有对应基础指法时保持明显空白，不得挪动相邻行或填入占位音。
  第一孔向侧方轻微偏移以贴近流行洞箫实物孔位；背孔仍保持管身中轴并使用专色。大图清楚
  显示开孔、闭孔和半孔三种状态。
- 每个单元格固定显示音名，并以独立唱名徽标显示唱名；禁止把两者拼成 `D3·5` 一类字符串。
  点击音名区域或唱名徽标都预览该单元格对应的完整指法。叉指或半孔等特殊基础指法可在单元格
  角落显示小型“叉”或“半”标记，但不得按指法类型另建轨道。
- 大洞箫始终只显示当前点选单元格或当前实时识别目标的完整指法。已点选时点选优先，
  再点同一单元格才交回实时识别；吹奏时同时显示 cents 偏差，下方继续使用小型表盘。
- 单元格的两种高亮必须一眼可分：实时命中实心填充，点选钉住只描边不填充，两者不得共用
  同一套底色与字重；无障碍状态分别播报「实时命中」「已钉住」「未选中」。
- 顶部“筒音作 X”只显示由当前唱名映射推导出的状态，不得实现成按钮、下拉框或选择器。
  用户直接纵向拖动任一唱名徽标来调整映射：越过整档时立即更新全部唱名并播放连续位移动画，
  主界面跨七个自然唱名档首尾循环，十二音详情独立跨 12 个半音档循环；G 调默认作 5 必须能在
  一次持续拖动中到达作 2。松手时提交到最近
  离散档并吸附归位，禁止停留在任意连续位置。落档更新全部唱名徽标及“筒音作 X”状态；
  十二音详情的固定音名、孔位和锚点不变；主视图则须一次性重筛七个基础行，使低音列始终完整显示
  `1 2 3 4 5 6 7`，不得出现以 `#4` 代替 `4` 的缺音状态。
- 点击主视图标题行的空白区域可打开独立的十二音详情。详情保留 12 个半音基础行与同样的
  三列布局，不得退化为七声表。主视图同时提供
  明确的“十二音详情”按钮作为可见、可访问入口；不得在主视图内原地展开。iOS 使用
  full-screen，Android 使用 full-screen dialog，macOS 使用大尺寸 sheet；三端都必须提供
  明确关闭操作并保留主视图上下文。
- 主视图和十二音详情共享同一个 `CaptureHub`/`AnalysisFrame`，不得新开麦克风或第二次分析；
  但两者各自拥有一支大型洞箫、滚动位置、单元格预览和交互状态。关闭详情后主视图回到打开前状态，
  详情重开也不得覆盖主视图状态；两个视图各自的单元格点选都高于实时识别，再次点击同一单元格
  才交回实时识别。
- 宽度允许时三个音区列同时可见；小屏手机必须保持大型洞箫可见，只让音区列区域横向滚动，
  或自动收起部分音区列并提供明确恢复方式。响应式变化不得隐藏洞箫、改变行锚点或合并音区含义。
- 音区列区域必须随实时命中音自动横向滚动，尽量把命中音所在列带到该区域中心，避免高音列
  长期滚在屏幕外。这是趋势算法：按列心与视口中心之差求位移，再夹到合法滚动范围，
  边界处只滚到能滚的最大值，不要求真正居中。只有实时命中的音区变化才触发滚动，
  单元格点选和用户手动滚动都不触发。
- 主页面仍以实时调音器为第一优先级：洞箫主表高度必须随屏高压缩并设上限，完整表盘、目标读数
  和状态不得被主表挤出或只剩残片；需要更大指法空间时使用独立十二音详情。
- 主视图与详情的大型洞箫图只表示 core 提供的主指法示范；乐器形制或流派可能存在替代指法，
  界面与无障碍文案不得宣称其为唯一权威指法。
- 各管乐差异：
  - 竹笛：线稿画出吹孔、笛膜孔（专色）与正面六孔，没有背孔与孔制切换；三列名称、唱名拖动转调、
    十二音详情与洞箫相同。
  - 尺八：线稿画出斜削歌口、四个前孔与一个背孔（专色）和根部；三列按八度命名为**乙音 / 甲音 / 大甲**
    （副标 otsu / kan / daikan）。尺八不提供唱名拖动转调（不显示“拖动唱名转调”提示，拖动无效），
    也不显示“十二音”入口。

主调音和乐器调音共享 core 的输入状态机；乐器页不得用本地定时器清空目标弦、指法或指针。
两个页面还必须复用同一套单指针呈现规则；下一次可信读数到达后立即以该值为唯一目标，
断音进入 `Holding` 时继续显示 core 返回的最后可信位置，不得补画历史针或动画归零。

## 3. 专业频谱面板

- 入口一：底部「频谱」标签；入口二：点击通用调音页的频谱分析带。两者进入同一页面和
  同一导航状态，返回调音页后继续沿用捕捉状态。
- 数据源：与主调音页共享 `CaptureHub` 的实时 `AnalysisFrame`，不得新开第二路麦克风，
  不得使用模拟频谱。
- 主图卡片顶部用紧凑分段控件切换「频谱 / 音高轨迹 / 波形」。三种视图复用原主图位置，
  不向下叠加新大图，不压缩连续时间图谱；切换不重启采集、不清空其他历史。
- 频谱增加「乐音 60–2400Hz / 全频 20Hz–上限」范围选择；乐音范围使用 64 个真实桶，
  全频范围使用 128 个真实桶，上限取帧内 `wide_spectrum_max_hz`，两者共享同一次 FFT。
  全频横轴在手机宽度固定使用 20/100/500/1k/5k/上限六档标签，频谱桶数量不因标签精简
  而减少。
- 主图：对数横轴 60–2400Hz、纵轴 -80–0dBFS，绘制全部 64 个实际频谱 bin；带刻度、
  网格和当前输入电平；绘制实时线与固定峰值保持线，支持触摸/拖动游标查看频率、dB 与
  最近实际峰的音名，并可暂停/继续。横轴固定显示 60/100/200/500/1k/2.4kHz，纵轴固定
  显示 0/-20/-40/-60/-80dBFS；0dBFS 是数字满量程上限，不是当前输入读数。标题区必须
  明确显示「实时刷新」或「已冻结」。主图表达当前频率分布，只随新帧改变幅值，不得伪装成
  沿横轴滚动的时间图。每个频率桶的峰值只允许被更强信号抬高，不按帧衰减，也不因弱信号
  或静音向下漂移。标题区提供「重置峰值」；点击只把各频率桶的峰值保持清到 -80dBFS，
  不清空实时曲线、连续时间图谱、六项摘要或实际峰值列表，也不改变暂停/继续状态。重置后
  下一张有效实时频谱帧重新开始累计峰值。
- 音高轨迹固定显示最近约 12 秒，横轴为时间，纵轴显示 MIDI 音高数值刻度；每个
  `Tracking` 且非保持帧追加一个由 `sample_position/sample_rate_hz` 定位的点。
  `Quiet`、`Acquiring`、`Holding`、暂停后恢复的第一帧都插入断点，禁止把最后读数保持
  画成持续发声，只在相邻真实追踪点间连线。
- 波形显示当前分析窗口的 256 列最小/最大包络，带 0 中线、振幅 -1/0/+1 刻度和
  毫秒时间刻度。波形只表达当前窗口，不累积为录音。
- 连续时间图谱：横轴与主图同为 60–2400Hz，纵向为时间，最新行在顶部。每 2 个分析帧
  写入一行颜色，固定保留 256 行（约 12 秒），暂停时与主图同时冻结。每行由 64 个真实
  测量桶线性插值为 96 个显示色块；插值只提高视觉细腻度，不增加频谱测量精度。左侧显示
  现在/-3/-6/-9/-12秒，底部显示与主图相同的频率刻度，右侧显示 -80～0dBFS 强度色标。
  颜色按深背景、靛蓝、紫、青、黄、红表达由弱到强的能量，网格必须在各档刻度位置可见。
- 峰值：绘制 `partials` 的所有实际峰，标出 H1/泛音序号、音名和一位小数 Hz；碰撞时错层。
- 摘要：在连续时间图谱前以两行三列显示音名、基频 Hz、音分偏差、输入 dBFS、最强实际峰
  （频率与强度）和和弦；每张摘要卡总高 52dp/pt、行间距 6dp/pt，最强峰允许两行；
  无对应数据时显示短横线，输入电平始终显示当前数值。
- 峰值表：按频率列出实际峰的频率、dB、泛音序号或独立音名，最多使用 core 返回的 8 项。
- 专业页保持原始实时更新，不受主调音页锁存影响；重复频率不得作为列表唯一标识。
- 暂停统一冻结三种主图、峰值保持、音高轨迹和连续时间图谱；恢复后轨迹从新段开始。
- 非目标：本阶段不录音、不保存音频文件、不提供回放、时间轴拖动或导出；界面不得出现
  这些不可用入口，也不预留对外半成品接口。

## 4. 节拍器面板

- BPM：大字 + 刻度环；垂直拖动 + 滑杆 + ±1/±5；30–250；tap tempo（≥2 次生效）。
- 摆锤动画随拍摆动；拍号 1/4–12/8 常用集；每拍重音圆点（点击循环 重拍/普通/静音）。
- 音色按常用程度显示：机械节拍 / 木块 / 电子滴声 / 拍板 / 边鼓 / 小鼓 / 牛铃 / 踩镲 /
  拍手 / 沙锤 / 低鼓 / 铃声。重拍（默认铃声）与弱拍（默认机械节拍）分别可选；选择状态
  沿用既有保存标识，异常或未知保存值安全回退到对应默认音色。
- 视觉闪拍与小节进度由 TickInfo 驱动。
- 播放/停止大按钮；播放中前台 Service 保活。

## 5. 设置页

- A4 校准：415–466Hz，步进 1Hz（显示 0.1）。
- 唱名体系：固定 Do / 首调 Do / 简谱数字 / 宫商角徵羽。
- 调式：12 主音 × 7 调式（与通用面板调性按钮同一份数据；固定 Do 时禁用）。
- 专业版模式：开 / 关（与通用面板 PRO 角标同源）。
- 律制：12 / 19 / 24 / 31 平均律（专业版开启时可见）。
- 灵敏度（噪声门限）：-60 ~ -30 dBFS，未保存过设置时默认 -45dBFS；既有保存值不迁移。
  显示当前数值，并解释数值越高
  越不容易被小声触发；修改后主调音和乐器调音即时共用。
- 主题：跟随系统 / 浅色 / 深色。
- 触觉反馈：开 / 关（默认开）。
- 顶部「小工具」卡片：一行说明列出当前工具（取自 core 列表），点击进入 §5.1 小工具页。

### 5.1 小工具页

- 入口：Android / iOS 从设置页顶部卡片进入（不新增底部 tab，底栏仍高亮「设置」，
  返回回到设置）；macOS 为侧栏独立入口「小工具」，位于节拍器与设置之间。
- 内容：按 core `list_tool_tones()` 顺序渲染工具卡片，每张显示名称、一行说明与播放/停止
  按钮；当前只有「防晕车」（100Hz 纯正弦波）。原生层不写死频率。
- 播放：复用音叉的正弦播放器（20ms 淡入淡出、同一增益与音频焦点）；同一时刻最多一路，
  点击正在播放的卡片停止，点击另一张卡片直接切换频率。播放中卡片描边与说明变为强调色，
  并追加「播放中」。
- 生命周期：只在前台播放。离开本页、切到后台或窗口失活时立即停止；移动端播放期间保持
  亮屏，停止后恢复系统熄屏。
- 页面底部固定一行提示：播放时保持亮屏、离开或后台自动停止；音频仅作舒缓辅助，不能替代
  药物或医疗建议。

## 6. 通用要求

- 深色/浅色完整适配（浅色无极光，用浅语义色渐变）。
- 行为变更必须同步本文件；视觉/动效变更必须同步 `docs/design-system.md`。

## 7. macOS 14+ 桌面行为

- 桌面端提供调音、乐器、专业分析、节拍器、小工具、设置六个完整入口，但导航改为
  `NavigationSplitView` 侧栏；不显示移动端底部标签栏。
- 调音页点击频谱预览直接选中同一个专业分析侧栏项。各入口使用同一份状态与
  `CaptureHub`，不得创建平行窗口或第二路分析会话。
- 宽内容区下，调音数据与频谱预览、专业分析主图与连续时间图谱可以并排；窗口收窄时按
  业务阅读顺序纵向排列。布局断点只改变摆放，不改变数据、历史或采集生命周期。
- 窗口失活或退出需要采集的页面时释放对应订阅；异步启动令牌和最后订阅者规则与 iOS 一致。
- 音叉选择器使用桌面浮层或 sheet；收起后继续播放，离开调音入口或窗口失活时停止。
- 管乐主视图和详情均采用“一支完整大型竖向乐器图 + 右侧三音区列”的桌面
  并排布局；三列都按实测指法填充，仅指法图未覆盖的格留空。点击标题行空白区域或
  “十二音详情”按钮，以大尺寸 sheet 打开独立十二音详情。
  sheet 与主视图共享采集和分析帧但各自保有滚动位置、单元格预览与交互状态；关闭 sheet
  不重置主视图。三列区域同样随实时命中音自动横向趋势居中。
- 麦克风拒绝时显示说明和打开系统设置操作；输入设备不可用时保留可重试界面，不崩溃。
- 完整业务、状态、失败回退和构建边界见 [macos-native.md](macos-native.md)。
