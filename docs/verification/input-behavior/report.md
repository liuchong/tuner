# 输入判定与保持验收报告

日期：2026-10-23；基线 `67ecbd6`，本报告所在提交交付完整实现。按全部设计、全部用例、全部实现、最后统一验收的顺序完成；最终验收发现的问题集中修正后复验。

## 已落地

- 三端共用Rust输入策略：自动环境门限/手动开关滞回、轻声/通用/较吵、起音和八度时间确认、削波和周期质量诊断。环境校准带进度、持续音调确认、取消与失败恢复，输入代次变化使环境估计失效。
- 迅速/均衡/平稳只影响显示，不改变raw测量与成绩。保持关闭/5秒/15秒/直到下次发声；完整原始帧与实时输入分开。回看优先，前一条件结果独立，停吹摘要采用末300ms的有效时间分位数、至少150ms覆盖，不挑最准点。
- 参考音污染排除；节拍器提示扬声器回采风险而不整段屏蔽。恢复输入不自动续录，停止后的晚到回调不能重建实时状态。
- 两端持久化旧门限迁移和新偏好；Android、iOS、macOS设置和工作区全部接线。手机优先读数、参数按需展开；桌面侧栏放输入与目标。schema2保存来源/判定参数，兼容schema1，CSV新增可信/显示频率和原因；不保存PCM。

## 原生观察与修正

- 当前macOS输入实测每批4800采样、hop1024。原4槽在批量交付时出现时间缺口，现固定16槽并丢弃有限启动积压；新增10000采样批次不丢hop用例。最终从设置页冷启动环境测量完成，显示背景与独立开/关门限，记录保持暂停；无音源校准不承诺乐器识别准确率。
- 桌面已确认响应偏好重启保留、设置/工作区共享、切换不把显示偏好当新成绩、设置采集租约交接、离页无输入及晚到回调防护。验收将响应恢复为原有“均衡”。
- Android原生确认选“平稳”到达真实Rust策略，环境测量状态/取消可操作，回看仍保留当前与基准频谱。截图来自测试夹具与真实JNI，不代表物理麦克风演奏。
- 修正了20Hz校准时刻随hop取整累积、Swift初始化/闭包、Compose导入、输入恢复旧文案、停止后晚到状态和手机参数抢占读数空间；另修正重新打开文件时最后一帧的配置归属：回看始终用该帧所属段，当前目标不覆盖旧结果；已有回归用例扩展了最后一帧和返回实时的断言。全部受影响门禁已复验。
- iOS模拟器原生构建与76项测试通过；本机没有Simulator.app图形应用，交互截图未验，不计为完成。
- 本机Xcode命令与xcresult均成功；受控外层发现Xcode结束后的辅助进程时返回125并回收，记录为`cleanup_complete=true`。产品测试依据结果包/独立命令核定，未把外层退出码冒充测试通过。模拟器、桌面实例均按归属收尾。

## 尚未覆盖的验收边界

A1–A12的逐条结果见[integration_test](../../../integration_test/input_behavior.md)。以上自动合同不等于全部实机场景通过。真实乐器80–1500Hz扫音、气声/尾响、不同房间和增益下误报/漏报、手机真实权限撤销与热插拔、耳机/扬声器实际回采、实际演奏延迟，以及完整大字/减少动态矩阵仍待实测。
