# Tuner 设计系统 —「Aurora / 极光」v4.0

> 跨平台设计圣经。Android（Compose）与后续 iOS/macOS（SwiftUI）共用同一套设计 token 与组件规格。
> 修改 UI 前必读；实现与本文档不一致视为缺陷（见 .agents/rules/docs-sync.md）。
> v4.0 修订：①布局均衡纪律（禁止拥挤/空旷）；②调性选择改为浮动展开面板（有过渡动画，
> 不留空白）；③音分历史带升级为**真实频谱分析**（FFT，含泛音标注）；④新增泛音/和弦面板；
> ⑤新增专业版模式与律制选择；⑥硬性修复「音名压指针」——读数永远不与表盘图形重叠。

---

## 1. 设计哲学

**「把舞台灯光握在手里」。**

调音的瞬间是演奏的一部分。界面应当像舞台灯光一样回应演奏者：发声时，整个屏幕的光随音准流动——偏低泛着珊瑚红的微光，接近时转为琥珀，准音的一刻薄荷绿的极光铺满屏幕顶部。**丰富，但每一个像素都在传递信息。**

四条原则（优先级递减）：

1. **一瞥即懂**：远距离（≈60cm）一眼读出「高了/低了/差多少」。构图纪律：表盘归表盘、读数归读数，任何文字不得压在任何图形上。
2. **光随音动（Reactive Aurora）**：背景极光的颜色、流动、亮度全部由当前音准状态驱动——界面是有生命的，静止时不无聊，变化时不吵闹。
3. **层次丰富、秩序严格**：后景极光 → 中景仪表 → 前景读数，三层纵深；每层有自己的密度，但同层内对齐严格（24dp 网格）。
4. **准音值得庆祝**：准音瞬间的光涌 + 触觉 + 极光全绿，构成心流奖励循环。

## 2. 反例清单（流行调音器为什么难看）

GuitarTuna（卡通吵闹、广告喧宾夺主）、Fender Tune（平淡无反馈）、Cleartune（拟物过时）、TonalEnergy（工程师堆砌）、Pano Tuner（空洞）。教训：不要幼稚化、不要工程师化、不要空洞化。丰富感来自**光、层次、动效**，不来自贴图和卡通。

## 3. 色彩系统

### 3.1 基础色板（Dark-first）

| Token | Dark | Light | 用途 |
|---|---|---|---|
| `bg/canvas` | `#0A0D17` | `#F6F7FA` | 底色（极光绘制在其上） |
| `bg/surface` | `#171C29`→`#1E2536` 纵向微渐变 | `#FFFFFF` | 控件/卡片底 |
| `bg/surface-raised` | `#232A3C` | `#FFFFFF` | 浮层、BottomSheet |
| `ink/primary` | `#F2F5F9` | `#14181F` | 主文字 |
| `ink/secondary` | `#9AA4B2` | `#5A6472` | 次要文字、单位 |
| `ink/faint` | `#525C6B` | `#A8B0BC` | 刻度、静置态 |
| `line/subtle` | `#2A3242` | `#E3E7ED` | 轨道、刻度 |
| `highlight/inner` | `#FFF` α5% | `#FFF` α60% | 控件顶部 1dp 内高光 |

### 3.2 语义色

| Token | Dark | Light | 语义 |
|---|---|---|---|
| `tune/in` | `#34E0A1` | `#0E9F6E` | 准（\|c\|≤5） |
| `tune/near` | `#FFC24B` | `#D97A00` | 接近（5<\|c\|≤15） |
| `tune/off` | `#FF6B6B` | `#E02424` | 偏离（\|c\|>15） |
| `accent` | `#7C9CFF` | `#3B5BDB` | 交互强调 |

- 语义色**只**用于音准反馈；颜色 + 位置（左低右高）+ 文字三重编码（色盲安全）。
- 对比度全部 ≥ WCAG AA。

### 3.3 极光与光效（Dark 专属）

| Token | 值 | 用途 |
|---|---|---|
| `aurora/state` | 语义色 α10~14%，半径 ≈1.2×屏宽 | 主极光：顶部偏左，颜色 = 当前音准语义色（无信号时 accent 蓝） |
| `aurora/base` | `#7C9CFF` α5% | 辅助极光：右下，恒定 |
| `glow/in` | `#34E0A1` α24%→0 | 准音光晕 |
| Light 主题 | 不用极光 | 用极浅语义色渐变背景（α4%）替代 |

动效：主极光中心点随 cents 轻微水平漂移（±3% 屏宽，弹簧插值）；亮度 6s 呼吸（α ±3%）。**漂移必须缓慢，不可分散对指针的注意力。**

## 5. 空间与布局

- 4dp 基数（4/8/12/16/24/32/48），页面边距 24dp，底栏 64dp。
- 拇指区：点按控件在下半 60%；展示在上半屏。触控目标 ≥48dp。
- **填充率纪律**：任何面板的内容填充率保持 75–90%，禁止出现 >15% 屏高的连续空白，也禁止控件间距 <8dp 的拥挤区。弹层（浮动面板/Sheet）收起后，原位置不得留「曾为弹层预留」的空洞——空间永远属于常驻内容。
- 通用调音页垂直结构（自上而下，按屏高比例分配）：
  - 表盘区 38%（含外圈数字环）
  - 音名读数 14%
  - 唱名+调性胶囊行 8%
  - 数据胶囊行 8%
  - 频谱分析带 16%
  - 泛音/和弦行 8%
  - 状态胶囊（底部安全区内，仅无信号时出现，出现时上方内容整体上移 8dp 弹簧过渡）
- 控件圆角 16dp，胶囊全圆角，播放键圆角 28dp。

## 6. 核心组件规格

### 6.1 Halo 表盘（屏上部，圆心不放任何文字）

同心三层，**圆心留空**（仅极淡内环 `line/subtle` α40%）：

1. **外圈数字环**：−50、−25、0、+25、+50（caption，`ink/faint`），沿弧排布。
2. **刻度带 + 彩色分区弧**：140° 弧（±50c）；10c 主刻度/2c 细分；分区弧红(±50→15)/琥珀(±15→5)/绿(±5)，线宽 6dp 圆头。
3. **进度光弧**：从弧左端（−50c）到当前指针位置的渐变弧（语义色发光，端部亮尾部透）——直观表达「离准音还有多远的路」。
4. **光针 + 残影**：锥形指针随偏差变色；最近 3 帧残影（30/15/7% α）。
5. **准音光池**：中心 ±5c 下方 `glow/in`；准音时 ×1.6 + 光涌。
6. 置信度低 → 指针 α 40%；无信号 → 指针 400ms 回中。

### 6.2 读数区（表盘正下方 8dp，与表盘明确分离）

- **音名**（display/note，随准度变色，准音时 scale 脉冲 1.0→1.06→1.0）。
- **唱名 + 调性胶囊行**（水平居中，间距 8dp）：
  - 唱名胶囊：`bg/surface` + 唱名文字（readout/solfege，ink/primary）。固定 Do 时显示唱名；无信号显示「—」。
  - **调性按钮胶囊**：与唱名胶囊同高同风格，`accent` 10% 底 + `accent` 文字「C 大调 ▾」。点击弹出调性选择（§6.3）。唱名体系为固定 Do 时禁用（α40%，点击 toast「固定 Do 无需调性」）。
- **数据胶囊行**：三个小胶囊（caption）：`440.0 Hz`、`+3.2c`（语义色）、`清晰度 92%`。

### 6.3 调性选择器（浮动展开面板）

- **浮动行为**：从调性胶囊位置向下展开的浮动卡片（`bg/surface-raised`，圆角 20dp，宽 ≈ 88% 屏宽，锚定胶囊）。展开时：卡片 spring 展开（scale 0.92→1 + fade，220ms），背景内容整体下沉 8dp + scale 0.98 + 遮罩 α38%（视觉重心转移到面板）；收起时反向弹回，**界面随动、不留任何空洞**。点击遮罩或再次点击胶囊收起。
- 内容：标题「调性」；主音网格两行六列（C C♯ D D♯ E F / F♯ G G♯ A A♯ B），选中 `accent` 填充；调式横向 chips（大调/小调/宫/商/角/徵/羽）。
- 选中即写入 DataStore 并即时生效（set_solfege），面板 200ms 后自动收起。
- 当前调性回显在 §6.2 调性胶囊上；固定 Do 时胶囊禁用置灰（点击 toast「固定 Do 无需调性」）。

### 6.4 频谱分析带（Spectrum Analyzer，真实数据）

- 位置：数据胶囊行下方，高 ≈16% 屏高，通栏。**数据源为 core 实时 FFT 频谱，禁止任何模拟/装饰性动画。**
- 样式：对数频率轴 60–2400Hz，64 柱（或折线+面积填充），柱色 `accent` 70%，随幅值明暗；dB 范围 -80~-10 映射高度。
- **泛音标注**：基频的 H1–H5 在对应频率位置顶部画小旗标（H1 主色 = 当前音准语义色，H2+ 为 `ink/secondary`）；非泛音的显著峰（partials）用空心圆点标记——用户能直接看到「这声音里还有什么」。
- 无信号时整体降至 `ink/faint` 并平线。

### 6.5 泛音 / 和弦行

频谱带下方，高 ≈8% 屏高：
- 左侧：泛音 chips（H2/H3/H4…，各显示相对纯泛音的 cents 偏差，|c|≤5 时 `tune/in` 描边）——弦乐/管乐泛音列纯度一眼可见。
- 右侧：和弦卡片——core 检测到 ≥3 个音级同时存在时显示和弦名（如 `C maj`、`Am7`），`bg/surface` 胶囊 + `accent` 文字；检测不到显示「—」。
- 无信号时整行灰显。

### 6.5b 状态胶囊

底部安全区：无信号时淡入的小胶囊（mic 图标 + 「请发声」，caption）。**禁止大号占位文字。**

### 6.6 乐器面板

- 顶部乐器选择：图标 + 名称的卡片行（当前卡片 `accent` 10% 底 + 描边）。
- 弦选择器：横排药丸（弦号/音名/唱名三层）；识别弦 `accent` 描边 + 外发光；准音弦 `tune/in` α12% 填充 + 右侧 ✓。
- 管乐指法列表：`bg/surface` 卡片列表，当前音项整行 `accent` 10% 高亮。
- 表盘复用 §6.1（半尺寸）。

### 6.7 节拍器面板

- **BPM 环**：大字居中 + 外圈 240° 刻度环（当前位亮点），垂直拖动调速，橡皮筋回弹。
- **摆锤**：经典倒摆动画，摆角随拍相位，重拍端点微顿；停止时缓动归中。
- **拍点行**：当前拍 ×1.5 + accent 发光；重拍实心/普通半透/静音空心。
- 播放键全宽高 72dp；播放中 `tune/off` 红。
- 拍号/音色：`bg/surface` 网格卡片区。

### 6.8 导航

底部 4 tab，线性图标 1.5dp，选中 `accent` 填充态；无徽标。

### 6.9 专业版模式（Pro Mode）

- **入口**：通用调音页右上角「PRO」角标按钮（`accent` 描边胶囊，关闭态 `ink/secondary` 描边）+ 设置页同款开关。开启后角标点亮并发微光。
- 开启后新增：
  1. **律制选择器**：唱名+调性胶囊行右侧出现律制胶囊（如「12-TET ▾」），点击弹出与调性选择器同风格的浮动面板：12 / 19 / 24 / 31 平均律（后续可扩展）。选择即写入 DataStore 并即时生效——表盘 cents 读数相对所选律制网格计算（音名仍按 12 平均律命名，附律制步序号，如 `19-TET · 7`）。
  2. 数据胶囊行追加「律制偏差」胶囊（相对所选律制最近级进的 ±cents）。
- 关闭时新增控件整体收起（200ms 弹簧），布局回退到标准三胶囊行——同样遵守填充率纪律。

## 7. 动效系统（全部 ≤400ms）

| 场景 | 参数 |
|---|---|
| 指针跟随 | 弹簧 stiffness 800 / damping 0.72（iOS `.spring(response:0.18, dampingFraction:0.72)`） |
| 极光变色/漂移 | 颜色 300ms 交叉渐变；位移弹簧 stiffness 60 / damping 0.9；呼吸 6s ±3% α |
| 准音光涌 | glow α 1.0→1.6→1.0，280ms FastOutSlowIn |
| 音名脉冲 | scale 1.0→1.06→1.0，300ms |
| 摆锤 | 拍相位正弦插值，端点 12% 缓动 |
| BottomSheet | 系统标准展开/收起 |
| 面板切换 | 交叉淡入 150ms，禁止位移 |
| 按钮按压 | scale 0.96，100ms |

## 8. 触觉反馈

进入准音区单次轻 tick；准音稳定 500ms 双 tick；离开不震；按钮系统默认；设置页可关。

## 9. 无障碍

色彩三重编码；WCAG AA 对比度；TalkBack 朗读「当前 A4，偏高 3.2 音分」「调性按钮，当前 C 大调」；动态字号 130%。
