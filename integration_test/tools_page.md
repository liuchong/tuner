# 小工具页 BDD 验收

## 场景 1：从设置进入小工具页

Given Android 或 iOS 打开吐呐的设置页  
Then 顶部显示「小工具」卡片，说明为「防晕车（100Hz 纯正弦波）」  
When 用户点击该卡片  
Then 进入小工具页，底栏仍高亮「设置」  
And 返回后回到设置页

## 场景 2：macOS 侧栏入口

Given macOS 14+ 启动吐呐  
Then 侧栏在节拍器与设置之间显示「小工具」  
When 用户选择「小工具」  
Then 详情区显示「防晕车」卡片

## 场景 3：防晕车播放与停止

Given 用户在小工具页  
When 点击「防晕车」的播放按钮  
Then 扬声器平滑淡入 100Hz 纯正弦波  
And 卡片描边变为强调色，说明追加「播放中」，按钮变为停止  
And 移动端播放期间屏幕不自动熄灭  
When 再次点击  
Then 声音平滑淡出停止，屏幕恢复系统熄屏规则

## 场景 4：离开或后台自动停止

Given 防晕车正在播放  
When 用户返回设置页、切到其他 tab、按 Home 键或让 macOS 窗口失活  
Then 播放立即停止  
And 再次回到小工具页时显示为未播放

## 场景 5：频率不随校准变化

Given 用户把 A4 校准改为 442Hz 或切换到 19-TET  
When 播放防晕车  
Then 频率仍为 100Hz
